# Largest number in an array

You are given `n` integers. Print the largest of them.

## Input

- Line 1: `n` (1 ≤ n ≤ 100000).
- Line 2: `n` integers (|a_i| ≤ 10^9).

## Output

One line: the largest integer.

## Example

Input

```
5
3 -7 12 0 12
```

Output

```
12
```

## Limits

Time limit: 1 second. Memory limit: 256 MB. Compiled with `g++ -std=c++17 -O2`.
